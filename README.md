# ElenyMakes.com
This Repository is for the design and deployment of elenymakes.com, an e-commerce website for selling crochet and knitting patterns. I made this webiste for a friend interested in selling her crochet and knitting patterns that would allow her to have more control over design without using standard design websites.

## Features:
* **Custom Storefront:** A unique UI designed specifically for the owner of [elenymakes.com](https://elenymakes.com)
* **Secure Downloads:** Leverages Supabase Storage buckets to securely host and deliver digital PDF patterns.
* **Order Management:** Automated logging of order history and pattern metadata using SQL.
* **Performance:** Optimized for speed and SEO using Next.js.

## Tech Stack:
* **Frontend:** React & Tailwind CSS
* **Framework:** Next.js
* **Database & Storage:** Cloudfare D1 and R2 storage (SQLite & Secure Buckets)
* **Deployment:** Cloudflare

## Project Status:
This is my first fully deployed website! I am committed to maintaining this platform, adding new patterns and supporting as the collection grows.

If you enjoy the design or find a pattern you like, please consider supporting the creator at [elenymakes.com](https://elenymakes.com).
